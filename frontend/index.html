Sobre o projeto

O Bora Formar é um sistema de gerenciamento de formatura desenvolvido para dar suporte às comissões de formatura em toda a organização financeira e administrativa do processo, desde a criação de salas por turma até o controle de mensalidades, rifas e movimentações de caixa.

O projeto nasceu na disciplina de Laboratório de Software II, do curso superior de Sistemas para Internet, e foi construído a partir de levantamento de requisitos com stakeholders reais, aplicando na prática todo o ciclo de desenvolvimento de um software: análise, modelagem, implementação e validação com os usuários finais.
